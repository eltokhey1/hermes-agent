## REA (“rea”) reverse-engineering evaluation — specifically requested

REA is a distinct tool *in addition to* the 50 and is **not** automatically integrated just because documented.

- Official site: https://rea.tools/
- Source: https://github.com/morluto/rea and https://github.com/morluto/rea/blob/main/README.md
- Installer/package: https://www.npmjs.com/package/rea-agents
- Setup and supported clients: https://github.com/morluto/rea/blob/main/docs/installation.md
- Latest GitHub release checked on 2026-10-26: `rea-agents-6.8.0`, published 2026-10-25: https://github.com/morluto/rea/releases/tag/rea-agents-6.8.0 . Official README states MIT license and support for JS/Electron, browser and native investigations, optionally Ghidra/IDA, and Hermes, Codex, Qoder as MCP clients. The repo's release is not evidence of installation on the user's Surface Pro.
- Runtime prerequisite per 6.8.0: supported Node.js `^22.23.4 || ^24.22.1 || >=26.12.1`; earlier 26.x, 23, 25 unsupported. Existing owner's Node version not presently verified.
- Safety: only owned/open-source/explicitly authorized targets; respect licenses, privacy and usage terms; no bypasses, credential retrieval, cracking, unauthorized live traffic or copying copyrighted assets. Reverse engineering explanations must include observed evidence, confidence/unknowns and a fresh independent clean-room implementation.
- **Windows read-only preflight** (user-run only; nothing remotely executed by this change):

  Review exact changes to Hermes MCP/skill configs. Installation command is intentionally NOT run. No automatic updates: no `@latest` in persistent registrations. Keep all executable tools subject to Hermes deterministic policy gate; MCP tool discovery by itself does not confer authorized effects.

## Repeatable lesson — teach and verify, do not repeat marketing copy

- **Minutes 0–5:** Explain AI agents vs LLMs vs API builders; trace one real task to input → tool → output → human decision; distinguish claimed capability from tested capability.
- **Minutes 5–12:** Find candidate in Product Hunt, Futurepedia, TAAFT, GitHub trending or HF Spaces; locate official docs, price, privacy/license, support/status. No star counts invented.
- **Minutes 12–20:** Execute a **synthetic or public** benchmark using existing free/local tool and one candidate, record exact-match, human review needed, cost/task, latency and failure rates.
- **Minutes 20–26:** Show REA investigation on owned/permissive sample only: source/behavior evidence → explanation → minimal original implementation → 3 tests. Do not equate REA tool availability with safe permission to reverse-engineer a third party.
- **Minutes 26–30:** Learner presents choice of best 3 tools and 5-step workflow, cites official sources, flags unknowns and names owner approval boundary.
