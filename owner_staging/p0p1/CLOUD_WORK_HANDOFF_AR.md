# أمر تسليم إلى Codex/Work أو Hermes المحلي — P0/P1 فقط

اقرأ أولاً `AGENTS.md` وسياسات المستودع الموجودة. حافظ على Hermes كنواة التنفيذ الوحيدة. لا تُضف orchestrator ثانياً أو LangGraph/CrewAI لمجرد توفرهما.

## المهمة

- ثبّت Git SHA الحقيقي وحالة working tree على الكمبيوتر، ثم اقرأ مرجع الـ45 حزمة والـ120 معرفاً دون نسخ أو ترقيم جديد.
- لا تستبدل أي ملفات موجودة؛ قارن SHA الأرشيف والملفات، وجرّب استيراد حزمة `Cloud_Local_Handoff` إلى مجلد جديد فقط باستخدام `local_stage.py` المتحقق منه.
- تحقق من نسخ جميع التبعيات إلى مجلد مؤقت لكل طفرة؛ baseline واكتشاف الاختبارات متطابقان. صنف ERROR/ImportError/ModuleNotFoundError/SQLite/Timeout/Discovery بوصفها INVALID وليس KILLED. لا تعلن mutation score كاملاً من عينة محدودة.
- نفّذ الفحوص السلبية في Docker/VM معزولة وعلى شيفرة اختبارية مصرح بها، لا على ملفات الإنتاج.
- ابنِ أدلة G0/G-CODE/G1 مع المصادر وأوقات التنفيذ وSHA وقوائم الاختبارات؛ أبقها NO-GO ما لم تتحقق شروطها المستقلة.
- النسخ الاحتياطي المقيد ثم **استعادة تشغيلية حقيقية في مجلد منفصل** قبل أي ترقيات أو تأثير على النظام. لا تفترض وجود Docker؛ تحقق منه أولًا.
- إذا ظهرت تعارضات أو أثر خارجي UNKNOWN: STOP / reconcile، دون replay أو retry ذاتي.

## ممنوعات

لا دمج ولا نشر ولا تكلفة مدفوعة ولا دفع ولا رسائل ولا تعديل trust kernel ولا تثبيتات بلا مراجعة. لا تدخل بيانات شخصية أو أسرار GitHub إلى مستودع عام. احتفظ بجميع العمل المحلي والملفات غير المتعقبة؛ لا reset/clean/update تلقائي.

## ختام التسليم

أرجع تقريرًا عربيًا يتضمن: المصدر والـSHA، الاختبارات التي شُغّلت فعلاً، البيئة ووقتها، ما الذي نجح/فشل، الفجوات، خطة الاستعادة، حالة كل بوابة، وأثر ذلك على الحزم الأصلية. لا تضع `PRODUCTION=READY` قبل مراجعة مستقلة.
