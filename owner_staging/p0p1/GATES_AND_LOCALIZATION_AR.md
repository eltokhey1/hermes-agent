# بوابات P0/P1 ونقل الحزمة من السحابة إلى Windows

**الانتقال الآمن ليس تركيبًا على الجهاز.** الترخيص العام بالعمل لا يلغي أدلة القبول أو موافقات عمليات الإنتاج الحساسة.

## الترتيب

| البوابة | الشرط | الحالي |
|---|---|---|
| G0 / P0-01 | هوية نسخة Windows وGit والعمليات والحقوق وجرد منقح للقراءة فقط | NO-GO؛ لم يُنفذ على الجهاز |
| G-CODE | سلسلة كود وتبعيات كاملة + اختبارات الوحدة وMutation السلبية وCI على SHA معين ومراجع مستقل | NO-GO؛ المختبر منفصل |

## على Windows عند إتاحته

1. تنقل حزمة الأرشيف من Library أو الفرع التجهيزي، وتحتفظ ببصمة SHA-256 الظاهرة في إيصال السحابة **خارج الأرشيف**.
2. تتحقق يدويًا: `Get-FileHash -Algorithm SHA256 'C:\Path\Hermes_Cloud_Local_Handoff_2026-10-20.zip'`. لا تكمل إذا اختلفت البصمة.
3. تحصل على سكربت `local_stage.py` من مصدر متحقق وبصمة مثبتة أيضًا؛ السكربت لا يمنع تشغيل كود ضار إذا وثقت به بلا مراجعة.
4. تنفذ باستخدام Python موجودة مسبقًا، دون تثبيتات أو امتيازات إدارية:

```powershell
python .\local_stage.py stage --archive "C:\Path\Hermes_Cloud_Local_Handoff_2026-10-20.zip" --sha256 "<64_CHAR_SHA256_FROM_CLOUD_RECEIPT>" --target "C:\HermesReview\staged-20261020"
```

اختر مجلدًا أبًا موجودًا ومجلد هدف **غير موجود**. استبدل قيم المثال فقط بعد التحقق؛ لا تنفذ النص بعلامات `<...>` حرفيًا.

5. `host-snapshot` اختياري للقراءة فقط ونتيجته منقحة دون مسارات أو بيانات أو أسرار:

```powershell
python .\local_stage.py host-snapshot --repo "C:\Path\To\Actual\HermesRepo"
```

لا تعتبر مجرد نجاح الأمر إثباتًا لصحة بيئة المضيف. تحقّق من صلاحيات الملفات والخدمات والـGit worktrees ثم نسخة احتياطية تشغيلية مستقلّة قبل أي استيراد إلى Hermes.

## التزام مزامنة

لا توجد قناة هذه اللحظة لتشغيل أمر على جهاز المستخدم أو تنبيه تلقائي عند اتصاله. لا تنفذ المزامنة من السحابة تلقائيًا دون وكيل محلي موصول ومصرح له. عند توفر هذه القناة: تبدأ بعملية اكتشاف قراءة فقط، وتحافظ على الملفات المحلية المعدلة وتنتج فرقًا/خطة، وبعدها تأخذ موافقة للإجراء المؤثر إن لزم.
