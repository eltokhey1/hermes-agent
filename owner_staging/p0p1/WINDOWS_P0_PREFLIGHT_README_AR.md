# Hermes P0-01 — جرد Windows للقراءة فقط

**الحالة:** أداة تحضيرية، لا تمنح اعتمادًا لبوابات G0/G-CODE/G1 ولا تثبت جاهزية الإنتاج.

لا يوجد في محادثة ChatGPT اتصال تنفيذي مباشر إلى Windows. تشغيل هذا الملف يجب أن يحدث **على جهاز Windows نفسه** بواسطة المستخدم أو داخل Work/Computer Use موصول فعليًا بالجهاز، بعد مراجعة الملف والتحقق من بصمته.

## كيف تستخدمه

1. احفظ `WINDOWS_P0_READONLY_PREFLIGHT.ps1` في مجلد تختاره داخل Windows، وراجع محتواه وبصمته مع `Get-FileHash`.
2. افتح **PowerShell عاديًا، دون تشغيل كمسؤول**، وانتقل إلى المجلد الذي يحتوي الملف.
3. إذا كان مسار مستودع Hermes المحلي معروفًا، شغّل الأمر (غيّر المسار إلى المسار الصحيح):

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\WINDOWS_P0_READONLY_PREFLIGHT.ps1 -RepoPath 'C:\PATH\TO\hermes-agent'
```

إذا لم يكن المسار معروفًا، شغّل الأداة دون `-RepoPath` وهي تتحقق من المجلد الحالي وعدد محدود من المواقع المعتادة، **دون البحث في كامل القرص**:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\WINDOWS_P0_READONLY_PREFLIGHT.ps1
```

**الإخراج:** JSON منقح يظهر في PowerShell ويُحفظ تلقائيًا في مجلد TEMP على جهازك. أرسل JSON النصي فقط إلى هذه المحادثة لمراجعة حالة P0. لا ترسل مجلد Hermes أو ملفات الأسرار أو بيانات الاعتماد. إذا ظهر `repo_detected=false`، أعد التشغيل بعد تحديد `-RepoPath` الصحيح.

## القيود

- لا يقرأ محتوى الأسرار أو متغيرات البيئة أو أسماء ملفات Git المعدلة، ولا يسرد مساراتك في JSON.
- لا ينفذ `git fetch`, `pull`, `checkout`, `install`, أوامر تعديل الخدمات أو تثبيت برامج.
- يوقف أي قفل Git اختياري أثناء استعلاماته، ويعطل fsmonitor/hooks في سياق أوامر الجرد. لا توجد ضمانات أمام أدوات محلية معدّلة أو بيئة مضيفة مخترقة.
- اختياريًا `-ProbeDocker` لفحص قابلية الوصول لخدمة Docker دون تشغيل حاوية؛ نجاح الاتصال **لا يعني إثبات العزل**.
- اختياريًا `-BackupDirectory` يفحص وجود مجلد فقط؛ لا يثبت تشفيره ولا الاستعادة الوظيفية.
- يجب عدم وضع الملف في شجرة Hermes الإنتاجية؛ يفضل مجلد منفصل في Downloads أو Documents.
- الترقية التالية (النسخ/الاستعادة المعزولة واختبارات P1) تتطلب خطة محلية مراجعَة وليست مشمولة هنا.
