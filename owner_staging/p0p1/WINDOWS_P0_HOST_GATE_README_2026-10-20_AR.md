# Hermes P0 — حزمة فحص محلي للقراءة فقط

هذه الحزمة ليست تثبيتًا أو ترقية وليست بديلًا للنسخ الاحتياطي الكامل. تعمل في Windows PowerShell 5.1 وتطبع تقرير JSON محدودًا دون إظهار أي مفاتيح أو محتوى YAML.

## كيفية التشغيل عند وجود المستخدم على جهازه

افتح PowerShell بالمستخدم العادي، ثم نفّذ من المجلد الذي يحوي السكربت:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\windows_p0_host_gate.ps1
```

لا تُنفّذ السكربت بصلاحيات Administrator لمجرد تجاوز `pending_messages`، ولا تغيّر ACLs أو ملكية المجلد. السكربت لا يكتب أو يحذف أو يفك تشفير أو يستخرج أو يرسل البيانات؛ ولا يشغّل حاوية ولا وكيلًا. إن واجه أي خطأ، يبقي الإنتاج `HOLD`.

## نطاق الدليل وحدوده

- يعيد التحقق من بصمات أرشيفي النسخ الجزئية المعروفين لدى المستخدم (650MB تقريبًا و28MB تقريبًا).
- يفحص قابلية إدراج المجلد `pending_messages` دون قراءة محتوياته.
- يتحقق من إمكانية الوصول إلى Docker Engine (ليس اختبار عزل Hermes)، ومن وجود التثبيت والمستودع المحلي، ومن علامات ESTOP المعروفة.
- لا يختبر الاستعادة الوظيفية؛ لا يثبت شمول النسخ الكاملة، ولا يلغي العمل الجاري عند ESTOP، ولا ينفّذ تغييرات في Windows.
- غياب بعض العلامات أو عدم ظهور ملف لا يبرهن على أن ESTOP الفعلي غير نشط؛ مسارات Hermes قد تتغير تبعًا للتهيئة.
- جميع بوابات G0/G-CODE/G1 مقفلة `NO-GO` والإنتاج `HOLD`، حتى مع نجاح البصمات.

## سياسة الإدماج

تُراجع النتائج محليًا دون مشاركة الأسرار. لا يُسمح بتطبيق تحديث Git أو نقل إعدادات أو تشغيل Hermes إنتاجيًا، حتى استكمال النسخ الكامل، اختبار الاستعادة الوظيفية، قبول ESTOP الفعلي، وإثبات العزل، وصدور موافقة بشرية على التغييرات المؤثرة.
